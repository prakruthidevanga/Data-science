# 📈 Data Science Academic Laboratories & EDA Assignments

Practical exploratory data analysis, data wrangling, and statistical feature analysis notebooks completed as part of the core undergraduate Data Science curriculum at Alliance University.

---

## 📌 Repository Overview

This repository captures foundational data science techniques in Python:
- **Data Wrangling:** Imputing missing values, removing duplicates, and transforming types using **Pandas**.
- **Exploratory Data Analysis (EDA):** Statistical summaries, correlation analysis, and distributions with **Matplotlib** and **Seaborn**.
- **Feature Engineering:** Scaling, encoding, and preparing tabular data for downstream machine learning tasks.

---

## 📂 Contents

- `Assignment1 (1).ipynb` — Data loading, cleaning, filtering, and initial statistical inspection.
- `Assignment2 Data science.ipynb` — Multivariate visualizations, distribution fitting, and correlation matrices.

---

## ⚙️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/prakruthidevanga/Data-science.git
   cd Data-science
   ```
2. Install dependencies:
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```
3. Run Jupyter:
   ```bash
   jupyter notebook
   ```
